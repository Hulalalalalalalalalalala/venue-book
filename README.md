# roottrace

roottrace 用于计算数据批次的 Merkle 根值，并提供命令行版本查询。

## 构建与运行

```sh
cargo build --offline
./target/debug/roottrace --version
```

输出：

```text
roottrace 0.1.0
```

## 计算批次的 Merkle 根值

```sh
./target/debug/roottrace root <文件路径>
```

计算成功时，标准输出只有一行由 64 个小写十六进制字符组成的根值（行末带换行），退出状态为 0。两个批次文件的根值相同，说明它们包含完全相同的记录序列；根值不同则说明内容或记录边界有差异。

根值采用 RFC 6962 第 2.1 节定义的 SHA-256 Merkle Tree Hash：每条记录的完整字节作为一片叶子，按文件中的先后顺序组树。重复出现的相同内容不会被去重或排序。

### 记录如何划分

文件按原始字节读取，只以 LF（`0x0a`）分隔记录，分隔符本身不属于记录：

- 记录中的空格、制表符、CR（`0x0d`）以及其他字节都属于记录内容，原样参与计算；非 UTF-8 字节也可以正常计算。
- 空文件表示零条记录。
- 单独一个 LF 表示一条空记录；连续的 LF 会产生空记录，例如 `a\n\n` 是 `a` 和一条空记录。
- 末尾的 LF 只结束最后一条记录，不会额外产生空记录，因此 `a\nb` 与 `a\nb\n` 的根值相同。
- 使用 CRLF 换行的文件中，CR 是记录内容的一部分，不会被忽略，所以 CRLF 文件与 LF 文件的根值不同。

注意空文件（零条记录）与只含一个 LF 的文件（一条空记录）是不同的批次，根值也不同。

### 错误与退出状态

- 缺少文件路径、参数多余或使用未知命令：标准错误输出用法说明，退出状态为 2。
- 文件不存在、路径是目录或读取失败：标准错误说明失败原因，退出状态为 1。

失败时不会向标准输出写出任何根值。
